# 謝昌宏｜成長進行式

這是一個以本人資料製作的個人特質網站。採用石墨黑首屏、冰藍強調色與冷白內容區，搭配俐落矩形照片和全版面研究敘事；使用原生 HTML、CSS、JavaScript，沒有框架、第三方追蹤或外部字型依賴。

## 開啟方式

1. **最快使用：**下載「謝昌宏_個人特質網站.html」，用現代瀏覽器開啟。照片、三份 PDF、文件預覽、CSS、JavaScript 都在同一個檔案裡，不需要其他素材、不需要網路。
2. **完整程式包：**解壓縮後，雙擊 `dist/index.html`，效果與單檔版相同。
3. **閱讀容易修改的原始碼：**開啟 `source/index.html`，搭配同資料夾的 `styles.css` 與 `script.js`。請保留 `assets/` 與 `documents/`，以維持照片及文件路徑。
4. HTML 本身就是程式檔。可用文字編輯器直接開啟；程式內含中文註解。

手機的檔案管理器有時只會顯示 HTML 文字或靜態預覽。請選擇「以瀏覽器開啟」或使用網站連結，才能操作互動功能。

## 程式包結構

| 路徑 | 用途 |
| --- | --- |
| `dist/index.html` | 可直接離線開啟的完整單檔網站 |
| `source/index.html` | 語意結構與完整中文內容 |
| `source/styles.css` | 色彩、排版、手機樣式、深色模式與動畫 |
| `source/script.js` | 分頁、選單、閱讀器、外觀設定與捲動互動 |
| `source/assets/` | 本人提供素材及 PDF 預覽影像 |
| `source/documents/` | 三份未改動的原始 PDF |
| `assemble.py` | 選用的單檔內嵌輔助腳本，僅使用 Python 標準函式庫 |
| `README.md` | 使用方法、修改指引、延伸練習與部署教學 |

網站執行不需要 Python、Node、npm 或建置流程。`assemble.py` 只在你修改「分檔原始碼」後，想重新產生單檔版時才使用：

```bash
python assemble.py
```

也可以直接修改單檔 HTML 的 `<style>`、主要內容與最後一段 `<script>`，無須執行任何腳本。單檔最底部的 `assetData` 是 Base64 資料，通常不需要手動修改。

## 最容易自行修改的地方

### 換文案

在 `source/index.html` 搜尋 `heroTitle`、`freshmanTitle` 或需要修改的中文句子。每個區塊上方都有說明其用途的中文註解。請不要修改分頁的 `id`、`aria-controls` 對應，除非同步更新全部關聯。

### 換照片

以自己擁有使用權的照片替換 `source/assets/portrait.webp`，並更新 `alt` 替代文字。其他素材同理。如果使用 JPG，也要同步更新 HTML 路徑，再重新內嵌。

### 更新 PDF

替換 `source/documents/` 對應 PDF 時，也要重製 `source/assets/` 中同名的逐頁預覽，並更新 `script.js` 內 `docs` 的 `pages`。原始 PDF 與圖片預覽是兩份資料，僅換 PDF 不會自動更改預覽。

## 五項延伸練習

### 1. 改強調色：已附可操作示範

按網站右上角外觀按鈕，可比較冰川藍、霧紫色、銀灰色。若要自訂，修改 CSS 起始的 `--accent`、`--accent-soft`、`--night`、`--highlight`，並同時檢查明暗模式的文字對比。

### 2. 全屏切換與一般捲動：已附切換功能

外觀設定的「章節吸附」預設關閉。開啟後，CSS 會套用 `scroll-snap-type:y proximity`，在接近章節時協助對齊。此處採柔和吸附，是為了保留長篇內容與手機閱讀的完整性。

若課堂想體驗較強的逐屏切換，可在一份實驗副本改成 `mandatory`，並對短章節加上 `min-height:100svh`。不要把長篇研究章節直接限制成固定高度，否則文字可能被裁切。

### 3. Sticky 敘事與放大：已實作，可繼續新增

研究區使用 `.research-stage { position:sticky; top:120px; }`。外層右側有四個 `.research-step`，JavaScript 依捲動進度更新 `--story-progress`，讓概念圖緩慢放大、切換階段標籤與阻斷示意。

新增第五步時：

1. 在 `source/index.html` 的 `.research-steps` 裡複製一個 `<article class="research-step">`，把 `data-step` 改成 `4`，改寫內容。
2. 在 `script.js` 的 `stepLabels` 陣列最後加入第五步標籤。
3. 若需要不同視覺狀態，在 CSS 新增 `.research-stage[data-active-step="4"]` 規則。
4. 手機版刻意取消 sticky，讓所有內容自然展開；請一併檢查。

### 4. 深色模式：已完成

預設跟隨 `prefers-color-scheme:dark`。也可從外觀設定手動切換；偏好保留在該瀏覽器的 localStorage。若儲存功能被限制，當前頁面仍能使用。所有非必要動畫集中在 `@media (prefers-reduced-motion:no-preference)`；減少動態效果時直接呈現內容，並停用平滑捲動與章節吸附。

### 5. GitHub Pages 部署練習

以下為自行部署方法；不會在沒有你的帳號授權下替你建立公開儲存庫。此單檔內嵌完整個人文件，公開前請確認要分享哪些內容。

1. 建立一個自己管理的 GitHub repository。
2. 把 `dist/index.html` 上傳到儲存庫最上層，檔名保留 `index.html`。也可把單獨下載的 HTML 改名成 `index.html` 後上傳。
3. 在 repository 的 **Settings → Pages**，將 **Source** 選為 **Deploy from a branch**。
4. 選擇已有檔案的分支，例如 `main`；資料夾選 **/(root)**，再儲存。
5. 等待部署成功後，使用 Pages 顯示的網站網址。後續更新同一個 `index.html` 即可更新網站。

## 無障礙與操作

- 手機顯示漢堡選單；按 Escape 可關閉。
- 分頁可使用方向鍵、Home、End；Tab 鍵只停在目前選取的分頁。
- 閱讀器可用左右鍵換頁，縮放滑桿上的左右鍵只調整縮放，不會換頁。
- Escape 可關閉對話框，焦點回到開啟它的按鈕。
- 所有圖片有替代文字。完整文件的可搜尋文字請使用「開啟原始 PDF」；圖片預覽本身不提供全文螢幕閱讀。
- 瀏覽器需支援原生 dialog、CSS sticky 與 IntersectionObserver。建議使用目前版本的常用瀏覽器。
