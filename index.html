海報先從癌細胞擴散與神經–腫瘤溝通的觀察出發，再由神經發育及突觸訊號相關基因的分析，聚焦 SAMX 的可能角色，並辨識候選交互作用蛋白 A2 與 C1。

研究背景與假說
02 / MODEL

精簡結構，
尋找共同介面。

先移除 SAMX 的低信心、不穩定區域，建立較穩定的核心結構 SAMXp。接著模擬其與已知及候選配體的交互作用，辨識出含有 α-helix 的共同結合區域。

計算預測 · SAMXp → 共同結合區域
03 / DESIGN

從結合介面，
設計候選胜肽。

以預測介面為設計目標，依結構信心、親水性與穩定性進行篩選，得到兩個候選胜肽。這是後續測試的起點，尚不能直接等同於已證實的結合或阻斷效果。

04 / VALIDATE

讓預測，

這個網站，如何被做出來？

以石墨黑首屏、冰藍強調色與冷白內容區，結合俐落矩形照片、全版面節奏與研究捲動敘事。使用原生 HTML、CSS、JavaScript；單檔版已內嵌本人照片、文件預覽與 PDF。

你可以動手改的地方

  1. 改顏色：從右上角切換三種強調色；也可修改 CSS 的 --accent。
  2. 比較捲動：在外觀設定開關「章節吸附」，觀察與自由捲動的差異。
  3. 增加敘事：仿照研究章節的 .research-step 新增步驟；完整程式包附新增方法。
  4. 深色模式：支援跟隨系統與手動切換；閱讀 CSS 中 prefers-color-scheme 的註解。
  5. 部署練習：完整程式包附靜態網站部署步驟。公開前先檢查嵌入文件中希望分享的個人資訊。
